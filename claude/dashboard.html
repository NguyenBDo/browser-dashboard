      Keyboard shortcuts

      Click Change, then press the new keys. Each shortcut can use up to 3 keys, for example Ctrl + Shift + K (modifier keys count as keys). Some combinations are reserved by your browser or operating system and can't be captured by a web page.

      EnterOpen the highlighted link, or run the web search
      Shift + EnterSame, but in the opposite tab behaviour
      ↑ ↓Change the highlighted link while filtering, or move in the engine list
      EscClear the search, then leave the search bar (or close the engine list)
